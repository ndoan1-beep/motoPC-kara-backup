# TC-01 TestProcess Prompt

チケット番号:
Redmine #8842

作業種別:
テスト（Playwright UI）

目的:
保存されていない売変・廃棄伝票で伝票取消ボタンを押下した場合、エラー `ERRCSARB0273` が表示され、取消処理およびDB更新が発生しないことをPlaywrightで確認する。

背景:
Redmine #8842では、保存済み伝票の取消時は元伝票を残して赤伝を登録する仕様に変更する。一方、未保存伝票は取消対象のエラートランが存在しないため、取消処理を実行せずエラー表示で止める必要がある。

対象機能:
- 売変・廃棄伝票入力画面 伝票取消
- `SalesChangeDisposalSlipInputUpdate.SlipDeleateButton_Click`

参照すべき資料:
- `Redmine_8842_テスト仕様書.md` の `TC-01`
- `Redmine8842.UnitTests/TestData.md` の 10行目（最新確定データ）
- `Redmine8842_テストケース_流れ.md` の `Flow 1`

前提データ:
- `TestData.md` 10行目の入力値を基準に、未保存伝票として扱う。
- 主な入力値:
- `@CorporationCode = 0001`
- `@StoreCd = 035`
- `@SlipTypeCd = 07`
- `@SlipDiv = 02`
- `@SlipNo = 010000017`
- `@DisposalChangeDate = 2026-07-24`
- 未保存状態で取消するため、取消前後で上記キーの新規DB更新・INSERTが発生しないこと。
- 上記キーに該当するテスト実行で新規作成された行が以下のテーブルに存在しないこと。
- `SARSlipHeaderError`
- `SARSlipDetailError`
- `SARSlipHeader`
- `SARSlipDetail`

Playwright作業範囲:
- 既存のPlaywright構成を確認し、既存のテスト配置・fixture・認証方式に合わせて `TC-01` 用のUIテストを作成または実行する。
- テスト対象URL、ログイン情報、DB接続情報は既存設定または環境変数を使用する。不明な場合は、テスト内に仮定を埋め込まず、必要な値をREADMEまたは実行ログに明記する。
- locatorは、可能な限り `getByRole`、`getByLabel`、表示テキストなどユーザー視点の指定を優先する。

テスト手順:
1. Playwrightで対象アプリへアクセスし、必要に応じてログインする。
2. 売変・廃棄伝票入力画面を開く。
3. 未保存状態の伝票を作成する。必要入力がある場合は画面上で取消ボタンが押下可能になる最小項目のみ入力する。店舗 `035`、伝票種別 `07`、伝票区分 `02`、売変・廃棄日 `2026-07-24` を使用し、保存処理は実行しない。
4. 取消前に、対象伝票番号 `010000017` が前提テーブルに存在しないことをDB確認する。
5. 伝票取消ボタンを押下する。
6. エラー `ERRCSARB0273` または同エラーに対応するメッセージが画面に表示されることを確認する。
7. 確認画面、完了画面、完了メッセージ `MSGCSARI0028` に遷移または表示されないことを確認する。
8. 取消後に、対象伝票番号 `010000017` について前提テーブルに更新・INSERTが発生していないことをDB確認する。

主な期待結果:
- `ERRCSARB0273` が表示される。
- `DelSARSlipNew` 相当の取消処理は実行されない。
- `SARSlipHeaderError`、`SARSlipDetailError`、`SARSlipHeader`、`SARSlipDetail` に更新・INSERTが発生しない。
- 画面は未保存伝票の入力状態、またはエラー表示状態に留まり、取消完了扱いにならない。

証跡:
- 取消ボタン押下前の画面スクリーンショット。
- `ERRCSARB0273` 表示後の画面スクリーンショット。
- Playwright trace、video、または実行ログ。
- DB確認SQLと実行結果。DB接続を自動化できない場合は、手動確認結果を証跡として残す。

制約:
- 本テストで本番データを使用しない。
- DBデータを作成・削除する場合は、TC-01用のテストデータ範囲に限定する。
- 既存アプリケーションコードは変更しない。
- UI表示テキストが環境差で変わる場合でも、エラーコード `ERRCSARB0273` の検証を必須とする。

完了条件:
- PlaywrightでTC-01のUI操作と画面アサーションが実行できること。
- DB更新なしの確認結果が残っていること。
- 失敗時は、失敗した画面状態、locator、前提データ不足の有無を記録すること。
