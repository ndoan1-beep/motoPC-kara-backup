# TC-14 TestProcess Prompt

チケット番号:
Redmine #8842

作業種別:
テスト（Playwright UI）

目的:
確認画面あり設定の場合、伝票取消ボタン押下時点ではDB更新や赤伝INSERTを行わず、確認画面 `SCRCSAR050208` へ遷移し、確認画面で確定後に取消処理が実行されることをPlaywrightで確認する。

背景:
Redmine #8842の変更後仕様では、確認画面ありの場合に取消ボタン押下だけでDB更新してはいけない。取消処理は確認画面で確定した後に実行される必要がある。

対象機能:
- 売変・廃棄伝票入力画面 伝票取消
- 確認画面 `SCRCSAR050208`
- `SalesChangeDisposalSlipInputUpdate.SlipDeleateButton_Click`
- `DelSARSlipNew`

参照すべき資料:
- `Redmine_8842_テスト仕様書.md` の `TC-14`
- `Redmine8842.UnitTests/TestData.md` の 10行目（最新確定データ / TD-02相当）
- `Redmine8842_テストケース_流れ.md` の `Flow 13`

前提データ:
- `TestData.md` 10行目（TD-02）の保存済み売変伝票を取消対象として用意する。
- 主な対象データ:
- `@StoreCd = 035`
- `@SlipTypeCd = 07`
- `@SlipDiv = 02`
- `@SlipNo = 010000017`
- `@SlipBranchNo = 1`
- `@DisposalChangeDate = 2026-07-24`
- `SAR_CheckDisplay_Off` により確認画面へ遷移する設定にする。設定値の名称とON/OFFの意味が環境で分かりにくい場合は、確認画面へ遷移する実動作を基準にして記録する。

Playwright作業範囲:
- 既存のPlaywright構成を確認し、既存のテスト配置・fixture・認証方式に合わせて `TC-14` 用のUIテストを作成または実行する。
- 取消ボタン押下直後と、確認画面で確定後の2段階でアサーションを分ける。
- DB状態のスナップショットを、取消ボタン押下前、確認画面表示後、確定後に取得する。

テスト手順:
1. Playwrightで対象アプリへアクセスし、必要に応じてログインする。
2. 確認画面あり設定であることを確認する。
3. 売変・廃棄伝票入力画面で、保存済み伝票 `010000017` を開く。
4. 取消前のDB状態を取得する。少なくとも元伝票の件数、`LogicalDelFlg`、赤伝枝番の有無を記録する。
5. 伝票取消ボタンを押下する。
6. `workEntity.ButtonId = "5"` 相当の状態で確認画面 `SCRCSAR050208` へ遷移することを確認する。画面上で直接確認できない内部値は、URL、画面ID、hidden項目、リクエスト、ログなど取得可能な根拠で確認する。
7. 確認画面表示時点で、DB更新・赤伝INSERTがまだ発生していないことを確認する。
8. 確認画面で確定ボタンを押下する。
9. 確定後、TC-02からTC-13相当の取消後状態になることを確認する。Playwrightでは最低限、完了状態、元伝票と赤伝の検索可能状態、修正不可状態を確認する。

主な期待結果:
- 取消ボタン押下後、確認画面 `SCRCSAR050208` へ遷移する。
- 取消ボタン押下直後、確認画面で確定する前はDB更新・赤伝INSERTが発生しない。
- 確認画面で確定後に取消処理が実行される。
- 確定後は元伝票と赤伝が検索でき、両方とも修正不可になる。

証跡:
- 取消対象伝票を開いた画面スクリーンショット。
- 確認画面 `SCRCSAR050208` のスクリーンショット。
- 確認画面表示時点でDB更新・赤伝INSERTがないことを示すSQL結果。
- 確定後の完了画面または完了メッセージのスクリーンショット。
- 確定後の一覧検索結果と修正不可状態のスクリーンショット。
- Playwright trace、video、または実行ログ。

制約:
- 確認画面表示前にDB更新する実装は不合格とする。
- `workEntity.ButtonId` をUIから直接検証できない場合は、取得可能な代替証跡を明記する。
- 既存アプリケーションコードは変更しない。

完了条件:
- PlaywrightでTC-14の確認画面遷移、確定前DB未更新、確定後取消実行を確認できること。
- 確認画面あり設定の値または実動作根拠が証跡として残っていること。
