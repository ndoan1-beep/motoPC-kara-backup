# 資料マッピングテーブル

## 1. 目的

本ファイルは、各フェーズを開始・完了する際に参照する資料マッピング表です。
作業者またはAIエージェントは、任意のフェーズで作業を行う前に入力資料を確認し、作業完了時に出力資料が揃っているかを検証します。

## 2. 運用ルール

- フェーズ開始前に、対象フェーズの「入力資料」が存在するか確認します。
- 入力資料が不足している場合は、該当資料を先に作成するか、`未確認事項・決定事項.md` に未確認事項として記録します。
- フェーズ完了時に、対象フェーズの「出力資料・成果物」が作成または更新されているか確認します。
- 出力資料は次フェーズの入力資料として扱います。
- 品質ゲートで差し戻しが発生した場合は、必要な上流フェーズの資料を更新します。

## 5. チェック用テンプレート

各フェーズの開始時と完了時に、以下の形式で確認します。

```text
対象フェーズ:

入力資料:
- [ ] 必須入力資料が存在する
- [ ] 内容が最新である
- [ ] 未確認事項が記録されている

出力資料:
- [ ] 必須出力資料を作成または更新した
- [ ] 次フェーズで利用できる粒度で記載した
- [ ] 追跡管理表へ反映した

判定:
- [ ] 次フェーズへ進める
- [ ] 差し戻しが必要
```
