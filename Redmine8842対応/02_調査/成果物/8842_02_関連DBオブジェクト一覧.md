# 8842_02_関連DBオブジェクト一覧

最新更新時刻：　2026年08月18日16:03:47

## 1. 前提

現在DB接続はできないため、DB関連は以下を根拠に整理する。

- MCP `query_database_architecture` で取得できたデータ層資産。
- MCP `read_source_file_range` で取得したDataAccess SQL。
- MCP `read_source_file_range` で取得したDataSet定義。

`query_database_architecture` では `SARSlipHeader`、`SARSlipDetail`、`SARSlipHeaderError`、`SARSlipDetailError`、`CMCAccountBook`、`SAR003` は個別DB資産として検出されなかった。
